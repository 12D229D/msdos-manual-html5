CD

Sintaxis

CD [/D] [unidad:][ruta]
CD ..
CD \

Descripción

Cambia el directorio actual de trabajo.

  • CD .. – Sube un nivel (directorio padre).
  • CD \ – Va a la raíz de la unidad actual.
  • CD sin argumentos muestra la ruta del directorio actual.

Opciones

  • /D – Cambia también la unidad actual de trabajo además del directorio.

Ejemplos

CD C:\Windows\System32
CD ..
CD /D D:\Proyectos
