TYPE

← Volver al índice · ← REN · CHKDSK →

Sintaxis

TYPE nombre_archivo

Descripción

Muestra el contenido de un archivo de texto en la consola. No es adecuado para archivos binarios (pueden mostrar caracteres no legibles).

Opciones

El comando no tiene switches adicionales.

Ejemplos

TYPE notas.txt
TYPE C:\Windows\directx.log
TYPE autoexec.bat
