REN / RENAME

← Volver al índice · ← CD · TYPE →

Sintaxis

REN nombre_archivo_viejo nombre_archivo_nuevo
RENAME nombre_archivo_viejo nombre_archivo_nuevo

Descripción

Renombra archivos o directorios. El archivo destino debe estar en el mismo directorio que el origen (no se puede mover con este comando).

Opciones

El comando no tiene switches; solo acepta los nombres de origen y destino.

Ejemplos

REN viejo.txt nuevo.txt
RENAME reporte.docx reporte_final.docx
REN *.txt *.bak
